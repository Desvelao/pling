Module pling.notifiers.webhook_transport

Generic HTTP transport for webhook-style notifiers.

"POST a JSON payload to a URL" transport, shared by every webhook-style notifier (Slack/Discord/custom webhook).

send (url, payload, headers, method)
POSTs (or sends via another method) a JSON-encoded payload to a URL.

Parameters:

  • url string destination URL; https:// routes through LuaSec, http:// through plain socket.http
  • payload table JSON-encodable payload table
  • headers table optional extra request headers, merged over the default Content-Type/Content-Length
  • method string optional HTTP method, defaults to "POST"

Returns:

  1. boolean ok
  2. string err present when ok is false
