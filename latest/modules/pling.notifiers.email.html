Module pling.notifiers.email

Email channel notifier.

Sends notifications by email over SMTP, using LuaSocket's bundled socket.smtp module.

Supports plain SMTP and implicit TLS (smtp_cfg.ssl = true, typically port 465, via LuaSec). STARTTLS (smtp_cfg.starttls = true, typically port 587) is deliberately NOT implemented: it requires speaking plain SMTP up through the STARTTLS command/response and then upgrading the same connection to TLS mid-stream, which socket.smtp's transport layer has no hook for - a correct implementation needs its own hand-rolled SMTP conversation, not a create factory. Rather than ship an untested half-implementation, :send fails fast with a clear error; use implicit TLS or a plain relay for now.
