Module pling.notifiers.audio

Audio channel notifier.

Plays a sound file for an audio destination by shelling out to paplay/aplay/ffplay (first available), parameterized by the destination's own file field.

send (destination, _notification)
Plays the destination's sound file. The notification argument is ignored.

Parameters:

  • destination table destination config: file (required, path to a sound file)
  • _notification table ignored by this notifier

Returns:
